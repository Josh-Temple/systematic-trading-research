# データ受入条件の草案

Status: DRAFT / METADATA_ONLY / NOT_AN_EXPERIMENT_SPECIFICATION

今回検査したものは公開仕様と商品メタデータ。株価全履歴の件数、欠測率、収益、戦略成績は未計算。この契約が書けたことはデータ品質PASSではない。

## 必要なデータと粒度

| データ | 粒度・必須項目 | 用途 |
|---|---|---|
| 売買価格 | 銘柄×東証営業日。調整前O/H/L/C、出来高、取引代金、JPY、ソースID、取得日時 | 約定シミュレーションと時価評価。NAVで代替しない |
| 営業日 | 東証の日付、営業/休場、タイムゾーンAsia/Tokyo | 月末判定と翌営業日執行。無約定と休場を区別 |
| 受益権分割等 | 銘柄×イベント。効力日、比率、単位、公表時刻、根拠 | 各時点までの単位で保有口数と総収益を再構成 |
| 分配金 | 銘柄×イベント。権利落日、基準日、支払日、税引前額、額の単位、公表/確定時刻 | 総収益信号、受取権と実際の現金入金を分離 |
| 商品履歴 | 上場日、償還/廃止、売買単位の有効期間 | 上場前の価格や現在単位を過去へ適用しない |
| 費用 | 適用期間、銘柄/口座条件、委託手数料、観測スプレッド/執行差、データ費 | 費用控除後の経済性。観測と仮定を区別 |
| キャッシュ | 保有可能な現金の利率・適用期間・既知時刻 | 現金比較。今回は0%の試算案であり実利率未確認 |

全ての入力にソースURL/契約、取得UTC時刻、原ファイルSHA-256、列仕様、日付・通貨・口数単位、取得範囲、権限/利用条件を付ける。認証情報と利用許諾のない価格データをpublic GitHubへ保存しない。代替プロバイダは事前に記録し、結果後に切り替えない。

## 優先する受入検査

| 検査 | 失敗が与えるリスク | 受入条件案 |
|---|---|---|
| キー・範囲・カレンダー | 重複や欠測で月次リターンと執行日が変わる | 銘柄×日付の一意性、予定営業日との差分、開始/終了日の全件確認。未説明差分が残れば停止 |
| 分割と単位 | 1306の2026年10分割を暴落と誤認、分配金100口表示を1口と誤認 | 公式イベントと実データを照合し、口数・価格・分配金・純資産の整合を確認 |
| 総収益 | 配当調整を誤認して信号を変える | J-Quants AdjCは分配金込みではない[S11]。別の分配金台帳から構成し、既に再投資済みの系列へ二重加算しない |
| 時点情報 | 遡及調整や後から確定した額が過去の判断へ入る | raw値とその時点までのイベントを使用。公表が間に合わない月は後知恵で補完せず停止/延期を仕様化 |
| NAVと市場価格 | 買えないNAVで利益を見積もる、外国市場との時間差を無視 | 信号・基準価額・約定価格を別列。次の東証営業日のraw始値が存在しない場合は架空約定を置かない |
| Nullと休場 | 無約定、2020-10-01の東証停止等を前値で埋める | J-QuantsのNullの意味[S10]を保持。forward fillで売買可能性を作らない |
| 分配金入金 | 権利落直後にまだ入金していない現金を再投資する | 受取権は評価に含め、実際の再投資可能現金は支払日以降。再投資指数と現金口座を区別 |
| 価格・スプレッド | 始値を無条件に約定保証、板の薄い銘柄の費用を過小評価 | スプレッド等の費用シナリオと観測値を併記。現実の約定を証明するには別途観測が必要 |

## 未確定事項と実行ゲート

1. 5銘柄の2017年末以降の価格・分配金・分割・売買単位の全履歴、利用権、公開可能範囲を確認する。月末13観測点を満たす最初の日を機械的に選ぶ案（2018年12月末が暦上の最早候補）であり、実際の開始日はデータ検査前に確定しない。
2. ETF分配金の完全な権利落日/支払日/時点情報が取れるかを確認する。J-Quantsに「配当金データ」があるというだけでは5ETFの必要データが揃うと認定しない。
3. 発行者の無料履歴は候補経路。NEXT FUNDSの履歴リンクは確認できたが、1306のリンク先再取得はACCESS_UNAVAILABLE。金の果実CSVは列説明まで確認し、本文未検査。無料で全OHLCと分配金情報が揃うとの結論は出していない。
4. 信号式、現金利率、執行延期/欠測処理、端数、ベンチマークのリスク比較法、費用シナリオ、標本、主評価指標、停止/判定条件を**結果を開く前に**固定する。複数案を市場結果から選ばない。
5. 合成データで分割・分配金・時点・欠測・口数/現金整合を確認してから、指定した歴史標本を一度実行する。歴史再現は外部論文公表後の選択であり、未閲覧でも自動的にconfirmatory holdoutとは呼ばない。

この提案はH3、DATA-HR-003、CSM-002のゲートを開かない。新規ETFの契約に既存研究の閲覧許可を転用しない。
