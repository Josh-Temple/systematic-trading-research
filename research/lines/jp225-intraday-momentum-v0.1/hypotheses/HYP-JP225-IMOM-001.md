# Same-day Nikkei 225 intraday momentum

For eligible 2025 TSE trading days, the return of the same Nikkei 225 mini quarterly front contract from the previous eligible TSE day's 15:30 JST price to the current day's 09:30 JST price is positively associated with that contract's 15:00-15:30 JST return.

A simple sign translation is also expected to have positive gross transaction-price expectancy:

- early return > 0 -> LONG from 15:00 to 15:30;
- early return < 0 -> SHORT from 15:00 to 15:30;
- early return = 0 -> NO TRADE.

This is a transaction-price predictability hypothesis, not a claim of executable net profitability.
